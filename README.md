# Telco Customer Churn Analysis

## Project Overview

This project focuses on data acquisition, data cleaning, preprocessing, and exploratory data analysis (EDA) using the Telco Customer Churn dataset.

## Objectives

* Inspect and clean customer data using Pandas.
* Handle missing values and check duplicate records.
* Explore customer churn patterns.
* Create visualizations to understand customer behavior.

## Tools and Technologies

* Python
* Pandas and NumPy
* Matplotlib and Seaborn
* VS Code and Jupyter Notebook

## Project Files

* **Jupyter Notebook:** Python code and EDA visualizations.
* **Project Report:** Documentation of the methodology, code, charts, and findings.
* **Cleaned Dataset:** Processed data used for EDA.

## Dataset Source

[Kaggle – Telco Customer Churn](https://www.kaggle.com/datasets/blastchar/telco-customer-churn)

## Key Outcomes

The project demonstrates data cleaning, descriptive statistics, and visualization of customer churn patterns.

## Conclusion

This project provides a foundation for understanding customer churn and preparing data for future predictive modeling.
